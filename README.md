# Chamber Designer

2 ストロークのチャンバー（膨張室）の寸法を入力し、中心軸に沿った長さと直径分布を変えずに曲げ、板金の展開図を A3 実寸 PDF で出力する Web アプリです。

## 開発

```sh
npm install
npm run dev     # http://localhost:5173
npm test        # ユニットテスト（vitest）
npm run build
```

## 構成

- `src/geometry/` UI に依存しない幾何計算（テスト対象）
  - `profile.ts` 測定点 → 累積位置・直径補間・内容積
  - `bend.ts` 曲げ（位置・方向・角度・半径）の曲率分布を弧長に沿って積分して中心軸を作る。セグメント長が構造上変わらないため、全長と各測定点の位置は曲げても不変
  - `shapeCheck.ts` 曲げ半径と自己交差の検査
  - `segmentation.ts` 直線の円すい台部品への分割（エビ管構成）
  - `unroll.ts` 両端を平面で切った円すい台の解析的な展開
- `src/output/` A3 ページ割り付け・PDF・SVG（画面プレビュー用）
- `src/store/` Zustand（曲げの 3 手順入力、ブラウザ内の自動保存）

## 精度と適用条件

- 展開は板厚中心の面で計算します。各部品の展開図と 3D 形状の切断線長・母線長の一致をテストで確認しています（相対誤差 0.1% 未満）。
- 近似が入るのは、滑らかな中心軸を直線部品の連なりに置き換える段階だけです。設計形状との最大ずれと、テーパー部の継ぎ目の合わせずれを画面に表示します。
- 幾何条件の維持は、排気性能が同一であることを保証しません。スプリングバックや溶接の収縮は考慮していません。
